# Мод для Drakensang и Drakensang: The River of Time

English version: [README.en.md](README.en.md)

Нативный мод для двух игр Radon Labs. Он скрывает интерфейс для скриншотов, даёт свободную камеру сквозь стены, переход на любой уровень через меню, большую дальность прорисовки и доступ к вырезанным локациям. Для первой игры есть ещё панель освещения и объединённый Фердок.

Файлы игр не изменяются. Мод подключается как `dinput8.dll` в папке игры, поэтому для удаления достаточно удалить его файлы. Файлов игры здесь нет, нужна своя копия.

## Поддерживаемые версии

| Игра | Файл запуска | Папка для установки |
|---|---|---|
| Drakensang (2008), Steam | `drakensang.exe` | `dist/drakensang/` |
| The River of Time с дополнением Phileasson, Steam | `drakensanga1.exe` | `dist/river-of-time/` |

- Адреса в игре привязаны к конкретным exe из Steam. На других сборках мод это определяет, отключает игровые функции и оставляет только скриншоты.
- Базовый `drakensang.exe` из River of Time пока не поддерживается, нужен именно `drakensanga1.exe`.
- Проверено только на Linux через Proton. На Windows мод не проверялся.

## Что работает в каждой игре

| Функция | Drakensang | River of Time |
|---|---|---|
| Скрытие интерфейса (F10) | да | да |
| Свободная камера (F11) | да | да |
| Меню уровней (F7) | да | да |
| Вырезанные и неиспользуемые локации | да | да |
| Скриншоты PNG (F3) | да | да |
| Включение и выключение тумана (F2) | да | да |
| Дальность прорисовки объектов и света, отключение зон видимости, дальняя плоскость камеры | да | да |
| Дальность и детализация моделей и деревьев | да | нет |
| Панель освещения (F1) | да | нет |
| Фердок целиком | да | нет |
| Партия к камере (F4) | да | нет |
| Заморозка времени (F6) | не реализована | не реализована |

## Установка

1. Откройте папку игры: в Steam нажмите правой кнопкой на игру и выберите **Управление → Просмотреть локальные файлы**.
2. Скопируйте всё содержимое `dist/drakensang/` или `dist/river-of-time/` в корень этой папки, рядом с exe. Вложенная папка `_mod` тоже нужна.

   В корне игры должны появиться такие файлы:

   ```
   dinput8.dll
   drakensang_mod.ini
   drakensang_mod_levels*.txt
   drakensang_mod_extras*.txt
   drakensang_mod_composites.txt   (только Drakensang)
   _mod/drakensang_mod.dll
   ```

3. На Linux откройте **Свойства → Общие → Параметры запуска** и добавьте строку:

   ```
   WINEDLLOVERRIDES="dinput8=n,b" %command%
   ```

   На Windows этот шаг не нужен.
4. Запустите игру и загрузите сохранение. Появится короткое сообщение мода, а в папке игры создастся лог `_mod/mod.log`.

### Удаление

Удалите из папки игры `dinput8.dll`, все файлы `drakensang_mod*`, папку `_mod` и уберите параметр запуска. Снимки остаются в папке `screenshots`.

## Управление

Клавиши переназначаются в `drakensang_mod.ini`.

| Клавиша | Действие |
|---|---|
| F1 | панель освещения |
| F2 | туман вкл/выкл |
| F3 | скриншот в PNG без оверлея мода, папка `screenshots` в корне игры |
| F4 | партия к камере; сначала включите свободную камеру и долетите до места |
| F6 | зарезервирована под заморозку времени, пока только показывает сообщение |
| F7 | меню уровней |
| F10 | интерфейс вкл/выкл |
| F11 | свободная камера |

**Свободная камера**

| Клавиша | Действие |
|---|---|
| мышь | обзор |
| W A S D | движение |
| Space / C | вверх / вниз |
| Shift / Alt | быстрее / медленнее |
| колесо мыши | базовая скорость |
| Q / E | наклон |
| Z / X | угол обзора |
| Backspace | сброс наклона и угла обзора |

Пока открыта камера или меню, ввод в игру не передаётся, поэтому партия не ходит.

**Меню уровней (F7)**

| Клавиша | Действие |
|---|---|
| ↑ ↓, PgUp, PgDn, Home, End | выбор уровня |
| ← → | точка входа |
| Enter | перейти |
| Esc | закрыть |

Пункт **★ Cut & unused locations** открывает вторую страницу. Там Enter ставит модель вырезанной локации в текущий уровень и включает свободную камеру. Убрать модель можно пунктом **✖ Remove placed model**.

**Панель освещения (F1, только Drakensang)**

| Клавиша | Действие |
|---|---|
| ↑ ↓ | параметр |
| ← → | значение (Shift — шаг ×5, Ctrl — мелкий шаг) |
| Backspace | сбросить параметр |
| Del | сбросить всё |
| 1–4 | загрузить пресет |
| Shift+1–4 | сохранить пресет |

Пресеты хранятся в `drakensang_mod_lighting.ini` в корне игры.

## Настройки

`drakensang_mod.ini` лежит в корне игры, у каждого параметра есть комментарий.

| Параметр | Значение |
|---|---|
| `unlimited_draw_distance` | объекты, персонажи и деревья не пропадают вдали |
| `unlimited_light_distance` | то же для источников света, может снизить FPS |
| `ignore_visibility_zones` | рисовать части уровня, скрытые зонами видимости |
| `fog_distance` | множитель дальности тумана: 1 как в игре, 0 без тумана |
| `far_clip` | дальняя плоскость камеры в метрах |
| `unlimited_model_distance`, `model_detail_distance`, `tree_detail_distance` | дальность и детализация моделей и деревьев, только Drakensang |
| `borderless` | окно без рамки вместо эксклюзивного полноэкранного режима |

## Фердок целиком (только Drakensang)

В меню F7 есть пункт **Ferdok — whole city**. Мод загружает площадь Праиоса, убирает барьеры и добавляет постройки остальных трёх районов, а за стенами высаживает лес. Постройки появляются через несколько секунд после загрузки.

Добавленные районы только визуальные: у них нет коллизий и NPC. Вид предназначен для полёта камерой и скриншотов, а не для обычной игры.

## Перед использованием

- Экспериментируйте на отдельном сохранении. Переход на уровень в обход сюжета может сломать квесты.
- В уровнях, которых нет в сюжете, скрипты могут вести себя непредсказуемо.

## Известные проблемы

- **F6 (заморозка времени)** не реализована.
- **`.dmp` при выходе из игры.** Если в уровень добавлены объекты мода, например Фердок целиком, игра при закрытии может записать файл `.dmp` в свою папку. Это её внутренняя проверка `this->resources.IsEmpty()`. Вероятная причина: мод держит ссылки на добавленные объекты до выхода. Игра в этот момент уже закрывается, файл можно удалить.
- **Прибытие в Таллон.** Мод переносит партию в центр города по приблизительным координатам.
- **F4** напрямую не проверялась. Тот же код проверен через команду разработчика `party`.

## Если что-то не работает

| Что происходит | Что проверить |
|---|---|
| Нет сообщения мода, `_mod/mod.log` не появился | Параметр запуска Steam и что `dinput8.dll` лежит рядом с exe |
| В логе `game profile: unsupported build`, работают только скриншоты | Сборка игры не поддерживается, см. раздел о версиях |
| `Lighting panel is not available in this game yet` | Панели нет в River of Time |
| `Level list missing` | В корне игры нет файлов `drakensang_mod_levels*.txt` |
| Падает игра | Приложите `_mod/mod.log` и `.dmp` из папки игры |

## Экспорт 3D-моделей в glTF

Скрипты работают с Python 3 и нужны только для экспорта, игре они не требуются. Проверено на Drakensang (2008).

```bash
pip install numpy pillow
export DRAKENSANG_DIR="/путь/к/Drakensang"

# Уровень целиком
python3 tools/export_gltf.py --level location09 -o murolosh.glb

# Одна модель
python3 tools/export_gltf.py --model _location_09_grounds/dungeon_murolosch_tempel -o temple.glb
```

Результат — `.glb` с текстурами, единицы в метрах, ось Y вверх. Остальные параметры показывает `--help`.

## Конвертация в блоки Vintage Story

```bash
python3 tools/gltf_to_vintagestory.py murolosh.glb --scale 1 -o murolosh
```

- `--scale` задаёт число блоков на метр.
- `-o` принимает имя без расширения. Скрипт создаст `murolosh.json` и `murolosh_preview.png`.
- Модели больше 1024 блоков делятся на части `murolosh_x0_z0.json` и так далее.
- `--thicken N` утолщает тонкие стены, `--no-water` убирает воду, `--families stone,wood` ограничивает материалы.
- Палитра блоков уже лежит в `tools/vs_palette.json`. Для новой версии игры выполните `--rebuild-palette --assets /путь/к/vintagestory/assets`.

Проверено на Vintage Story 1.22. Скопируйте `.json` в `VintagestoryData/WorldEdit/` (на Linux это `~/.config/VintagestoryData/WorldEdit/`) и выполните в игре:

```
/we import murolosh
/we paste
```

## Сборка из исходников

Нужны clang, lld и Wine с 32-битными заголовками и библиотеками импорта. На Arch Linux:

```bash
sudo pacman -S clang lld wine
./build.sh                                      # DLL попадут в build/ и dist/
./build.sh all --install "/путь/к/Drakensang"   # и сразу в игру
./build.sh core --install "/путь/к/игре" --reload   # перезагрузить ядро в запущенной игре
```

`--install` не перезаписывает существующий `drakensang_mod.ini`. На других дистрибутивах пути задаются переменными `CC`, `LLD_LINK`, `WINE_INCLUDE` и `WINE_LIB`.

### Перегенерация данных

Списки уровней, локаций и объединённый Фердок строятся из файлов игры.

```bash
export DRAKENSANG_DIR="/путь/к/Drakensang"
export DRAKENSANG_ROT_DIR="/путь/к/Drakensang The River of Time"

python3 tools/gen_levels.py d1 --out dist/drakensang
python3 tools/gen_extras.py d1 --out dist/drakensang
python3 tools/gen_composites.py --out dist/drakensang
python3 tools/gen_levels.py rot_a1 --out dist/river-of-time
python3 tools/gen_extras.py rot_a1 --out dist/river-of-time
```

### Поддержка новой сборки игры

1. Поставьте `dump_image=1` в секции `[dev]` и запустите игру. Мод запишет расшифрованный образ exe в `_mod/dump/`.
2. Установите capstone: `pip install capstone`.
3. Найдите адреса с помощью `tools/re/`, обновите таблицы в `tools/re/gen_profiles.py`.
4. Запустите `python3 tools/re/gen_profiles.py`, он создаст `src/core/profiles.inc`.

Дампы содержат расшифрованный код игры, не публикуйте их. Папка `dump/` уже есть в `.gitignore`.

Настройка `command_file=1` включает канал разработчика: мод выполняет команды из `_mod/cmd.txt` и пишет ответы в `_mod/cmd_out.txt`. Список выводит команда `help`.

## Структура

```
src/loader/   dinput8.dll: прокси и долгоживущие хуки
src/core/     drakensang_mod.dll: все функции, перезагружается на лету
src/shared/   конфиг и лог
tools/        генераторы данных, экспорт glTF, конвертер в Vintage Story
tools/re/     анализ дампов и генерация профилей игр
dist/         готовые файлы для установки
```
